# VideoCraft Skill
> 开源AI Skill，面向抖音、小红书15–60s短视频创作，零基础快速产出视频。支持剧情、科普、VLOG、悬疑题材，题材无限制。可手动切换新手/专业模式。

## ✨ 能力清单
1. 选题生成：用户无想法时，一次性输出5个混合风格选题，附带核心看点简介
2. 脚本创作：输出简略故事脚本 + 精细AI绘图提示词；支持一次性生成两套不同主题脚本
3. 内容品类：剧情 / 科普 / VLOG / 悬疑，支持多题材混合创作；悬疑可设计反转伏笔
4. 输出内容：选题、脚本、分镜、标题、封面文字（主标题+副标题+小字备注）、小红书/抖音标签（各最多4个）、剪映剪辑参数、BGM名称+风格说明
5. 两种模式
    - 新手模式：通俗易懂，少专业术语，附带剪映分步操作指引
    - 专业模式：增加镜头节奏、转场思路、调色建议
6. 脚本风险自检：检查敏感表述、夸大宣传、违规话术、素材/BGM版权风险，在对应位置标注风险
7. 局部重生成：支持单独重写某一模块（封面/标题/分镜等），同步更新绘图提示词，新旧版本给出对比
8. 成片复盘：接收用户视频描述，输出：优点 + 待优化点 + 剪映修改建议；支持同时复盘多条脚本
9. 科普内容自动校验：规避绝对化用词；文末标注知识点可自行查证，医学/法律类额外标注仅作科普参考，不可替代专业意见
10. VLOG脚本自带镜头捕捉提示，字幕口语化；合法前提下，融合参考公开平台免费Skill的爆款创作思路

## 📋 使用流程
1. 用户手动选择模式：新手模式 / 专业模式
2. 缺少信息时一次性收集全部必填项：题材类型、视频风格、目标平台、时长、画面比例
3. 生成全套短视频创作素材

## 📌 示例
> 新手模式 · 科普短视频
> 选题：手机长期放枕边的隐性影响
> 看点：颠覆日常习惯，简单易懂，贴近普通人生活

> 专业模式 · 剧情短视频
> 选题：便利店深夜的短暂相遇
> 看点：短反转，情绪留白，适合抖音竖屏

## 📁 导入方式
1. 复制prompt.md全部文本，粘贴到AI系统提示词框直接使用
2. 在支持yaml导入的Agent平台，导入skill.yaml加载Skill

## ❓ FAQ
Q：这个Skill可以自动联网抓取小红书/抖音Skill吗？
A：本Skill是提示词驱动，内置公开爆款创作范式。如需实时联网检索外部Skill，需要在Agent平台额外开启联网搜索插件。
